## Development

Next.js 14 App Router, Tailwind CSS, Framer Motion and React Icons.

```bash
npm ci
npm run lint
npm run build
npm run dev
```

Content is maintained in `data/projects.js`, `data/journey.js`, `data/skills.js`, and `components/Writing.jsx`. Each page section has a corresponding component in `components/`.

Project links point to public repositories or test/demo deployments where available. Testnet applications are not represented as production financial services.
